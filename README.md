# 📝 To-Do App (React + CDN)

A simple, clean, and responsive **To-Do Application** built using **HTML, CSS, and React JS (via CDN)**. This project focuses on core React concepts and provides essential task management features with a smooth user experience.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit existing tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as completed  
- 🔍 Filter tasks (All / Active / Completed)  
- 📊 Progress tracking with dynamic progress bar  
- 💾 Data persistence using localStorage  
- 🧹 Clear all tasks option  
- 📱 Fully responsive design (mobile + desktop)

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript (ES6)  
- React JS (via CDN)  
- Babel (for JSX support)

To-Do App

## ▶️ How to Run

1. Download or clone this repository  
2. Open the `index.html` file in your browser  
3. Start adding your tasks 🎉  

_No installation required_

---

## 💡 How It Works

- Tasks are stored in **localStorage**, so data persists after refresh  
- React **useState** manages tasks, input, and filters  
- React **useEffect** syncs tasks with localStorage  
- Components:
  - `App` → Main logic & state management  
  - `TaskCard` → Task UI with edit/delete
